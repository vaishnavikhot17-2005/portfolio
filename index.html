Software Development Intern · Toyota Kirloskar Motor (TKM)

During my internship, I worked on developing a digital solution to modernize the paint inspection process in an automotive manufacturing environment.

The existing inspection process relied heavily on paper-based check sheets, which made it difficult to store, retrieve, track, and analyze historical inspection data. My work focused on transforming this manual process into a centralized digital system.

What I worked on

  • Developed responsive and user-friendly interfaces for creating and managing digital paint inspection check sheets.
  • Worked on the frontend using React.js and integrated it with backend REST APIs.
  • Developed backend APIs using ASP.NET Core Web API.
  • Designed and worked with SQL Server databases for storing users, check sheets, inspection sections, and inspection results.
  • Implemented user authentication and role-based access for different users.
  • Developed functionality to upload inspection-section images and place inspection points dynamically on those images.
  • Worked on storing the position of inspection points so that the same inspection template could be reused.
  • Implemented the flow for entering inspection results and comparing them against required values.
  • Worked with database relationships and Entity Framework Core to connect the application with SQL Server.
  • Tested and debugged the application across frontend, backend, and database layers.
  • Gained practical exposure to understanding requirements directly from an industrial workflow and converting them into a working software solution.

Key learning

This internship gave me practical experience in full-stack application development, from understanding real-world requirements and designing the UI to developing APIs, connecting databases, testing, and debugging.

More importantly, I learned how software can be used to replace manual processes with structured, traceable, and easily accessible digital workflows.
